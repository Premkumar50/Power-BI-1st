# Power BI-(Project 1st)

## Project Overview

This project focuses on analyzing e-commerce sales data using Microsoft Power BI. The dashboard presents sales data through interactive visualizations to help understand business performance, sales trends, and key insights.

## Tools & Technologies

* Microsoft Power BI
* Microsoft Excel

  ## Dataset used
- <a href="https://github.com/Premkumar50/Power-BI-1st/blob/main/Ecommerce_Sales_Datset.xlsx">Dataset</a>
- <a href="https://github.com/Premkumar50/Power-BI-1st/blob/main/Poewr%20BI%20(1).pbix">Dashboard</a>

## Project Files

* `Ecommerce_Sales_Datset.xlsx` – E-commerce sales dataset.
* `Poewr BI (1).pbix` – Power BI dashboard project file.

## Key Features

* Interactive sales dashboard
* Sales performance analysis
* Data visualization using charts and graphs
* Identification of sales trends and patterns
* Business insights to support data-driven decisions

## Learning & Development

I developed this project by following a YouTube tutorial to gain practical experience with Power BI, data visualization, and dashboard development. I used this project to strengthen my understanding of data analysis concepts and business reporting.

## How to Use

1. Download or clone this repository.
2. Open the `.pbix` file in Microsoft Power BI Desktop.
3. Connect to the Excel dataset if prompted.
4. Refresh the data if required.
5. Explore the dashboard and its visualizations.
